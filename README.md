# tthcc_an

Analysis repository for the Run 3 boosted `ttHcc` study.

## Overview

This repository is intended for:

- event selection and skimming
- object reconstruction and boosted topologies
- truth matching and control studies
- histogram production and plotting
- systematic checks and validation

## Planned Structure

- `config/`: analysis configuration files
- `scripts/`: helper scripts for skimming, plotting, and utilities
- `src/`: core analysis code
- `notebooks/`: exploratory studies and quick checks
- `outputs/`: local analysis outputs (not tracked in git)

## Getting Started

Clone the repository and set up your working environment:

```bash
git clone git@github.com:Waldeinsamkeit123/tthcc_an.git
cd tthcc_an
```
